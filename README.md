## 💡 Proyectos & Laboratorios
 
### Proyectos Actuales
 
**JARVIS** — Laboratorio personal de integración de IA, reconocimiento de voz, automatización domótica y Machine Learning aplicado a sistemas inteligentes. Plataforma de experimentación con tecnologías abiertas de asistentes.
 
**Anomaly Detection & Statistical Analysis** — Modelos exploratorios para detección de patrones y anomalías mediante métodos estadísticos, reglas de negocio y análisis multivariado. Aplicado a monitoreo y decisiones organizacionales.
 
### Proyectos Profesionales Destacados
 
**Cerebro MTS** — Plataforma de inteligencia organizacional que integra datos, IA y decisiones estratégicas. Arquitectura AWS (Data Lake C1-C5), ingeniería de datos, modelos predictivos, MLOps y GenAI. Impacto: +30 productos analíticos, 400+ usuarios, 5.000+ colaboradores en 5 países.
 
**Currency Converter** — Aplicación en Java para conversión de divisas en tiempo real usando APIs de intercambio, con procesamiento robusto de datos financieros.
 
**Foro Hub Challenge** — Aplicación web Spring Boot para gestión de foros educativos. Autenticación con JWT, operaciones CRUD, filtrado, paginación y búsqueda avanzada.
 
**Literalura** — Sistema de gestión de libros integrando PostgreSQL y APIs públicas. Parsing de datos, persistencia robusta y búsqueda avanzada.
 
**Data Visualization Dashboard** — Dashboard interactivo en Python y Power BI para visualización de datos de ventas, insights para marketing.
 
**Customer Data Pipeline** — Pipeline de limpieza, transformación y análisis de datos masivos usando Pandas. Optimización de performance y reducción de errores.
 
**Text Encryptor** — Aplicación web (HTML, CSS, JavaScript) para encriptación/desencriptación de mensajes. Oracle Alura ONE program.
 
**Kaggle Projects** — Análisis de datos y machine learning aplicados a desafíos reales.
